# Career Readiness Checker

## About

Career Readiness Checker is a Python application that asks users about their skills and career goals, then provides personalised feedback based on their responses.

This is my first portfolio project as I learn Python and software engineering.

---

## Features

- Welcome screen
- User profile collection
- Career profile display
- Personalised encouragement
- Project progress feedback
- GitHub account check
